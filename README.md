# Computational-Modelling-Of-Tumour-Burdening-Using-Cf-DNA-Signatures
Multi-head neural network for tumor burden estimation from cfDNA methylation signatures — trained on TCGA-BRCA tissue, validated on plasma cfDNA (breast cancer detection, purity, T-stage, N-stage, progression).

## Overview

- A 661-CpG panel is selected via differential methylation analysis (tumour vs. blood reference).
- Synthetic tumour–blood mixtures are generated at 8 tumour fractions (0–100%) to simulate cfDNA.
- A shared-encoder multi-task network (661→512→256→128→64) predicts five outputs: cancer detection, purity, T-stage, N-stage, and progression.
- The trained model is validated zero-shot on real plasma cfDNA (GSE122126, GSE214344).

## Data requirements

Not included in this repo — source these yourself before running:

- **TCGA-BRCA methylation data** (450K array) — GDC portal
- `uuid_mapping.tsv`, `files_manifest.tsv`, `triple_overlap_cases.tsv` — TCGA metadata
- `data/raw/biospecimen/slide.tsv`, `data/raw/clinical/clinical.tsv` — TCGA clinical/biospecimen data
- **GSE40279** (Hannum 2013, 656 whole blood 450K methylomes) — blood reference
- **GSE122126** — plasma cfDNA validation cohort
- **GSE214344** — metastatic breast cancer plasma cfDNA (optional, for extended validation)
- **Aran et al. 2015 tumour purity table** — [download link](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fncomms9971/MediaObjects/41467_2015_BFncomms9971_MOESM1236_ESM.xlsx), or place manually at `data/raw/aran2015_purity.xlsx`

## Setup

```bash
pip install -r requirements.txt
```

Install PyTorch separately with the correct CUDA/CPU build from [pytorch.org](https://pytorch.org) rather than a plain `pip install torch`.

## Results

| Metric | Value |
|---|---|
| Tissue test purity (Pearson r) | 0.983 |
| Tissue test cancer detection AUC | 0.929 |
| T-stage balanced accuracy | 0.32–0.38 (chance = 0.250) |
| N-stage AUC | 0.51–0.54 (chance = 0.500) |
| Zero-shot cfDNA AUC, all cancers vs healthy (GSE122126) | 0.976 (p = 0.00003) |
| Zero-shot cfDNA AUC, breast only vs healthy | 1.000 (p = 0.0022, n=3) |
| Single-task ridge regression baseline (purity) | r = 0.881 |

Purity and cancer-detection results are strong. T-stage shows a weak but real signal above chance; N-stage shows no detectable signal — both are discussed as biologically expected outcomes (tumour size and lymph-node status are not strongly encoded in bulk methylation).

## Known limitations

- The Aran et al. purity merge (`04_purity_merge.py`) is not a fully automated pipeline step — column names in the source spreadsheet may need manual verification against the script's expected names.
- The zero-shot cfDNA breast-cancer AUC (1.000) is based on only 3 positive samples — a small-sample result, not a robust estimate.
- GSE214344 samples show a batch effect relative to GSE122126 healthy controls; scores are not directly comparable across the two cohorts.
- T-stage and N-stage metrics vary somewhat run-to-run due to low signal-to-noise in those heads.
- Model is trained exclusively on breast cancer tissue; cross-cancer generalization (Figure 18-style gradient across disease groups) is observed but not the primary validation target.
